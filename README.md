# Sales-And-Revenue-Analysis-Dashboard
Sales and Revenue Analysis Dashboard:
An interactive dashboard built to learn data visualization, KPI tracking, and business insights generation. It uses KPIs, filters, slicers, and charts to analyze sales performance, revenue trends, profitability, and customer behavior, enabling users to uncover actionable insights and make data-driven decisions.

## Sales & Revenue Dashboard – Process


## 1.Import Data
*Load Excel/CSV/Database sales data into Power BI or Excel.

## 2.Clean Data
*Remove errors, fix formats, ensure correct date & numeric fields.

## 3.Create KPIs
*Total Sales
*Total Revenue
*Average Order Value

## 4.Build Visuals
*Line chart → Revenue trend
*Bar chart → Top products
*Pie chart → Category sales

## 5.Add Filters
*Use slicers for Region, Date, Category.

## 6.Design Dashboard
*Place KPIs on top, charts in center, filters on side.

## 7Get Insights
*Identify top products, trends, and performance gaps.
